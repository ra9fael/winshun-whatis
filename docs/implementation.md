# 原生实现说明

[English](implementation.en.md)

## 关键裁决

先确认窗口创建进程，再说明归属边界。Windows 无法读取的路径保持未知；不把父进程、文件名或页面标题推测成内容应用。用户于 2026-11-08 批准此前的设计及 HTML 原型后实施此开发预览。

## 结构

- `src/core/selection.h`：不依赖 Windows 的状态机、会话代次、候选身份和结果。
- `src/platform/window_probe.*`：窗口命中、HWND/PID、标题、类名、根窗口、有限权限进程路径与创建时间。
- `src/ui/window.*`：专用 UI 线程、单个路径查询工作线程、原生控件、选取输入层、边框、提示和结果卡。
- `src/main.cpp`：stdio JSON-RPC 入口与诊断 CLI；宿主查询无窗口副作用，动作立即返回隐藏启动器效果。
- `winshun.h`：本地复制的宿主 SDK，增加线程安全异步工具调用；详见第三方说明。

查询携带递增代次与 HWND/PID，取消、换候选及确认都会使旧响应失效。确认时重新查询；锁定后以创建时间辅助检测 PID 复用。跨进程标题使用缓存标题读取，避免发送无界 `WM_GETTEXT`。

## 相对原型的调整

### 2026-11-08 界面修订

用户确认功能可用并要求改善外观。本轮落实原方案的紧凑结果卡：统一标题栏，程序图形与 EXE 主标题，独立路径容器，成组主次操作，底部详情和重新选取。中文采用微软雅黑 UI，英文采用 Segoe UI；自绘图形使用抗锯齿，按钮保留原生键盘/可访问性语义并提供悬停与焦点状态。空态隐藏无效表单，普通归属说明移入详情，错误仍直接可见。权限、查询及选取逻辑沿用现有实现。验证包括深浅色/双语/空态/拒绝访问截图、原有集成检查与真实宿主往返。

1. 实际选取使用每屏一个 alpha=1 的临时 layered 输入窗口。它接收选取按下/松开；高亮边框和提示不激活且穿透输入。通过 Z 序枚举其下方窗口，跳过自有窗口、隐藏窗口、cloaked 窗口、桌面与明显透明层。区域和子窗口检查保留跨进程子窗口 PID，同 PID 子控件归一到根窗口。不宣称能复现所有应用自定义命中逻辑。
2. 不安装全局鼠标钩子。拖动采用鼠标捕获；退出、取消、前台丢失、输入桌面变化或 30 秒超时撤销输入层与捕获。真实输入隔离仍需手工验证。
3. 宿主动作路径没有授予前台权限；动作延后 120 ms 开始，Windows 拒绝激活时回到置顶卡片，要求用户点击继续。未修改主程序。
4. 源码按实际复杂度收敛为核心、平台、UI 三部分；会话通过统一递增 generation 表达。首版不保存 owner 链、采样时间或独立内容应用身份。
5. 宿主命令动作只有 `pick`。复制与详情是原生控件动作；定位使用 `show_in_folder`，超时为 5 秒，迟到回复丢弃。文件有效性由宿主在工作线程检查，插件 UI 不同步访问文件系统。
6. 实际首屏复用结果卡空态，显示选取入口；高级详情折叠。原型中的模拟 Explorer 仅用于交互讲解，原生定位交给宿主。

## 边界与失败

| 情况 | 行为 |
|---|---|
| 路径拒绝访问 | 保留 HWND/PID 和错误码，禁用路径动作 |
| 窗口关闭 | 标记历史快照；查询时失效则不保存路径 |
| ApplicationFrameHost / RuntimeBroker | 显示已读取的宿主 EXE，内容应用未知 |
| 复制失败 | 显示错误，路径文本仍可选择 |
| 定位错误 / 工具超时 | 展示宿主错误或超时，恢复按钮 |
| 失去前台 / 桌面切换 | 取消，撤销输入层，显示结果卡 |
| 没有候选 | 继续等待有效窗口或 Esc |

## 已验证与未验证

实测：无需主程序改动即可经过真实宿主装载和工具往返；正常沙箱中可以读取测试窗口 EXE；真实 DACL 拒绝访问按预期降级。输入层通过系统命中检查，定向消息完成选取。31 项集成、12 项真实宿主检查及 CTest 2/2 通过。

推断：临时输入层应消费普通桌面确认点击，创建时间有助于检测 PID 复用，原生架构有利于控制资源占用。这些不等于物理输入、高压复用或性能验收。

尚未验证的完整清单及 L0–L5 对应关系见 [验证文档](validation.md)。
