# 图标修复 0.1.1

[English](icon-validation.en.md)

## 问题是什么

ICO 嵌入程序后，原生窗口仍可能使用通用图标。

## 为什么

资源声明不等于窗口图标设置。IDI_ICON1 是字符串资源名。Qt 界面需要显式应用图标资源。

## 改了什么

修复可执行文件图标，补齐打包中的 ICO 和资源脚本。 为窗口显式设置大小图标，随 DPI 更新并释放图标句柄。 自绘标题栏显示同一插件图标。

## 实测

2026-11-09：从提交副本以 MSVC 19.51 / x64 Release 构建；CTest 2/2 通过。资源和真实插件进程检查 21/21 通过（docs/icon-checks.json），含命名资源、8 个尺寸、协议初始化和正常退出。 独立图标回归另有 46/46 项通过，包含 DPI 和 66 次外观切换；此前用户已确认安装后图标正常。

## 没测的

未自动操作真实任务栏与 Alt+Tab 切换；没有重新验证所有插件功能、硬件路径、跨显示器实际拖动、UAC 安全桌面或全部 Windows 版本。本轮只制作本地标签和安装包，未公开发布。 早前实际启动 whatis 的宿主探针在退出时出现 0xC0000005；原版插件也复现，图标回归的独立进程正常退出。此旧宿主问题未在本轮修复，不能据此声称完整发布验收通过。
